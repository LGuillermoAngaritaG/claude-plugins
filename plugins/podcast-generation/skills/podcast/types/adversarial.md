# Adversarial

Date line `<!-- YYYY-MM-DD adversarial -->`.

Two hosts with different views on one question, so the listener leaves with the whole
picture and can make up their own mind.

| speaker | role | voice en / es |
| :-- | :-- | :-- |
| HOST_A | holds the first view, and opens and closes | af_bella / ef_dora |
| HOST_B | holds the other view | am_michael / em_alex |

- Each host has forty to sixty percent of the words. The lint checks HOST_B's share.
- Never two turns in a row by the same host.
- **Pick a real question.** It must be one where informed people actually disagree.
  If the evidence is settled, this is the wrong type: use two hosts or professor.
- **The shape.** HOST_A opens with the question and names both views fairly in one turn.
  The three things are then: what both sides agree on (the facts), where they differ and
  why, and what would change each host's mind.
- **No false balance.** Say how strong the evidence is on each side ("most studies",
  "one small study", "no data yet"). If one side has much stronger evidence, the hosts
  say so, even the host on the weaker side.
- **Strongest form.** Each host gives the best version of their view, never a weak
  version of the other's. Before disagreeing, a host repeats the other's point in a
  sentence the other would accept.
- Facts and values apart: say when the disagreement is about what is true, and when it is
  about what matters more.
- Polite and direct. No mocking, no "you clearly don't understand".
- The ending is not a winner. HOST_A sums up where they agree, where they still differ,
  and what the listener could look at to decide. HOST_B adds one line, HOST_A signs off.
- For a topic people act on (health, money, law), research it first and keep a facts file
  (see "Facts and history" in the skill).
