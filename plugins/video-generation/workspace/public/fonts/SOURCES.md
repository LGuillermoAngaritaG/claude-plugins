# Fonts

All from the Google Fonts repository, https://github.com/google/fonts. They are loaded by the look files in `src/kits/`.

| file | family | used by | licence |
|---|---|---|---|
| `Caveat.ttf` | Caveat (variable weight) | hand-drawn videos | SIL Open Font License 1.1 |
| `BebasNeue.ttf` | Bebas Neue | story titles | SIL Open Font License 1.1 |
| `Montserrat.ttf` | Montserrat (variable weight) | story captions | SIL Open Font License 1.1 |
| `SpecialElite.ttf` | Special Elite | story case-file stamps | Apache License 2.0 |
